# R497 — Source/Pool Reconstruction Next Goal

**Date:** 2026-06-14
**Status:** started; research-only; no submission artifact.

## Why This Is The Next Goal

The valid Blind-A anchor is the R432s/R106-family profile: **nDCG 0.5092, LLM 4.90,
composite 0.6387**. R495/R496 closed the last low-risk provided-data reorder path:
rank-preserving semantic promotions are LLM-safe but not nDCG-positive. Moving past
**0.60 nDCG** needs roughly eight clean rank-1 recoveries, which ordinary retrieval,
reranking, response edits, and local top-20 reorder policies have not produced.

The only remaining high-ceiling mechanism is recovering the hidden source-session /
candidate-pool identity described in TalkPlayData-2. That is research-only unless the
organizers explicitly allow external-data session matching.

## Hard Gates

- **No Codabench upload** from this line until organizer permission is explicit.
- **No unofficial LFM-2b mirrors.** LFM-2b is withdrawn for license issues.
- **No hidden-label lookup.** The feasibility metric is whether a source fingerprint
  narrows a row to a plausible session/pool, not whether it directly finds the GT.
- **CPU-first.** Do not run MPS-heavy jobs on the Mac; avoid another OOM.

## Next Work

1. Obtain or confirm lawful local access to MLHD/MLHD+ metadata only if license terms allow
   this research use.
2. Run `scripts/lfm_source_auditor.py` on a small MLHD prefix to confirm schema:
   timestamp, per-user file identity, recording MBID, and demographic join availability.
3. Build a **no-GT feasibility matcher** for the three bridgeable rows:
   `ca8cbe02`, `a1df8767`, and `2bfd631e`. Match by date window + demographics +
   played-track recording-MBID overlap.
4. Success criterion: a row is feasible only if the matched source session recovers the
   played history and yields **<=100 plausible candidate tracks** without using hidden GT.
5. If no rows meet that criterion, source reconstruction is closed for lawful data.

## Current Decision

Do not spend another Blind-A slot on semantic reorder/modeling variants unless a new offline
result shows enough expected nDCG to matter. The only route with enough theoretical headroom
is source/pool reconstruction, and it must be handled as a rules-cleared research track.
